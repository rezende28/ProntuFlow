# 🏥 DocMed

Sistema web para gerenciamento de solicitações de prontuários médicos.

## 📌 Sobre o projeto

O DocMed é um sistema desenvolvido para otimizar o controle e acompanhamento de solicitações de prontuários médicos.

O projeto nasceu a partir de uma necessidade observada durante minha atuação no Arquivo Médico hospitalar, buscando transformar um processo manual em uma solução digital mais organizada, segura e eficiente.

O objetivo é facilitar o gerenciamento das solicitações, permitindo acompanhamento de prazos, histórico de alterações e controle das informações.

---

## 🚀 Funcionalidades

✅ Cadastro de solicitações de prontuários

✅ Controle de solicitações físicas e digitais

✅ Cálculo automático de prazos

✅ Dashboard com indicadores

✅ Gráficos de acompanhamento

✅ Login de usuários

✅ Controle de permissões

✅ Histórico de alterações

✅ Gerenciamento de status das solicitações
